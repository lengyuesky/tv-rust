# 飞牛播放中换源与统一作品目录验收

日期：2026-11-21（Asia/Shanghai）。用户要求在飞牛客户端实际播放时切换来源，并合并“我的剧集”重复作品及详情中的来源列表。本轮替代先前通过季／版本卡片展示来源的方案。

## 实现与参考

参考 [funwukong/fnmedia-ext](https://github.com/funwukong/fnmedia-ext/tree/eaf4a535d54c9d760358c8efd923d7dfe644052e)，检出提交为 `eaf4a535d54c9d760358c8efd923d7dfe644052e`，重点核对 `proxy/app.py` 中 `_qualities`、`_line_bitrate`、`_line_of_bitrate`、`stream` 和 `media.resetQuality`：将来源作为飞牛清晰度菜单项，使用稳定整数选择码，详情仅提供当前媒体。

- 播放器底部画质／来源按钮显示当前来源；菜单显示来源名称及实测分辨率，按画质由高到低排列。同源多线路带编号，未知画质明确标识。完整尺寸、编码、帧率及实际码率继续通过媒体详情提供。
- 当前媒体对应的菜单标签和选择码写入起播协商，避免客户端误选排序第一项。菜单选择码与真实媒体码率分别使用，不能用选择码宣称实际码率。
- 飞牛搜索、收藏、我的电影／剧集和继续观看按作品去重，作品、季和确认集号的单集采用稳定身份。每部剧一季，统一目录补齐授权来源可确认的缺集，简介保持作品原文，详情仅一份当前媒体信息。
- 来源需满足账号授权、同作品、同集和地址未变更。菜单绑定账号和登录会话，重启保留身份；切换验证失败不结束旧来源，成功后结束旧会话，迟到上报不会覆盖新来源。
- 网页跨源续播规则不变；飞牛播放中换源由原生播放器控制播放位置，实际回传归入当前选中的来源。服务端不在换源前复制旧源记录。
- 删除记录会同时禁止旧来源菜单和播放会话写回。正在播放的媒体可继续，删除后再切源仍不能恢复记录；主动重新起播创建新菜单和会话，之后正常记录。
- 单源保留 STRM 直链；多源使用本站短期菜单地址，空认证头的请求跳转原媒体，带本站认证头的请求使用受全局开关限制的同源转发。原源地址与查询签名保持原样。
- 移除来源 PNG 及 8 MB 中文字体、`png` 和 `ab_glyph` 依赖，镜像不再包含来源标签字体。

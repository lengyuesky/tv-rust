# 播放页快速换源与具体画质验收

日期：2026-11-20（Asia/Shanghai）。用户要求播放页快速切换播放源，并显示具体画质；本轮沿用已确认的账号授权、同作品匹配与来源独立进度规则。

## 最终行为

- 播放器下方显示当前来源和单集；同一影片有多条播放线路时提供下拉框。点击“切换播放源”展开同作品候选，首次展开可复用搜索缓存，手动“刷新来源”必须重新请求上游。
- 候选需标题、明确年份、类别和版本一致，列表仅包含当前账号获准使用且启用的来源。不同年份、不同剪辑及仅标题包含的作品不会进入候选，列表不交付单集媒体地址。上游部分失败时其余结果仍可选择。
- 按当前播放的实际集号匹配，例如原目录第二项“第03集”对应新目录第三项“第三集”，不按目录位置匹配，也不依赖已保存进度。正片需明确标记；重复集号、合集及无法确认的版本先让用户选集。
- 目标详情准备成功且集数明确时，保存旧会话最终快照、结束旧会话并自动开始目标播放。详情请求失败保留原播放；需要手动选集时，确认前原播放继续。连续重复点击只创建一次目标播放。
- 同一影片切线路承接当前时间；跨来源使用目标来源已有进度，不复制旧来源时间。自动播放成功后清理一次性 URL 参数，返回和前进不会重新执行旧的自动播放请求。
- 播放器上方显示真实分辨率、编码和帧率，例如 `实际画质：720p · 1280 × 720 · H.264 · 24 fps`。服务端缺失探测信息时不编造默认 H.264，浏览器解码后补充实际尺寸；HLS 档位信息仅在尺寸对应时用于编码和帧率。未知时显示“画质待识别”，手机端同样可见。
